# Project 2 — Sweet Crumbs Bakery

A responsive bakery and cake shop website made with beginner-friendly HTML and CSS.

## Files
- index.html — webpage structure, navigation, product cards, images and email link.
- style.css — typography, colors, spacing, borders, box model and responsive layout.
- test_cases.txt — manual test checklist.
- output/SCREENSHOT_INSTRUCTIONS.txt — screenshot steps.

## Run
Keep index.html and style.css in the same folder, then double-click index.html. Internet is required for sample online images.

## Topics
HTML5 structure, headings, links, images with alt text, CSS selectors, text/background colors, fonts, borders, padding, margin, viewport and responsive design.
