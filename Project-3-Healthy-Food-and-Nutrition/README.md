# Project 3 — FreshPlate Healthy Food Guide

A responsive educational website about balanced food choices and everyday healthy habits, made with HTML and CSS.

## Files
- index.html — page structure, navigation, links, images, lists and content cards.
- style.css — typography, colors, backgrounds, borders, spacing, grid and responsive design.
- test_cases.txt — manual tests.
- output/SCREENSHOT_INSTRUCTIONS.txt — screenshot steps.

## Run
Keep index.html and style.css together and double-click index.html to open it in a browser. Internet is required for sample online images.

## Topics
HTML5 structure, semantic sections, hyperlinks, images and alt text, lists, CSS selectors, fonts, text/background colors, borders, padding, margin, viewport and responsive design.

This website provides general educational information, not personal medical advice.
