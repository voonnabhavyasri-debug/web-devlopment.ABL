USER INTERFACE DESIGN

Design for Everyone

Good design principles

  • Use clear headings and readable fonts.
  • Keep enough spacing between sections.
  • Choose colors with good contrast.
  • Make navigation easy to understand.
  • Make the layout work on mobile screens.

Accessibility tip

Add descriptive alternative text to meaningful images and use clear link text.
