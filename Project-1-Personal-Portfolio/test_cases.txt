WEB DEVELOPMENT PROJECT — MANUAL TEST CASES

TC1: Open index.html in a browser.
Expected result: The webpage loads and the header, hero section, and footer are visible.

TC2: Click HTML, CSS, Design, and Contact in the navigation.
Expected result: The page moves to the matching section.

TC3: Check the lists under “Lists and Images”.
Expected result: An unordered list and an ordered list appear.

TC4: Check the sample image.
Expected result: The image appears with descriptive alternative text if it cannot load.

TC5: Check the CSS examples.
Expected result: Typography, background colors, borders, padding, and box-model examples are styled.

TC6: Resize the browser to a narrow/mobile width.
Expected result: Content fits the screen and cards display in one column.

TC7: Resize the browser to a wide/desktop width.
Expected result: Cards appear in multiple columns.

TC8: Click “Send an Email”.
Expected result: The default email application opens with the sample address.

TC9: Use the keyboard Tab key to navigate links.
Expected result: A visible focus outline appears on focused links.

TC10: Click “Back to top”.
Expected result: The page returns to the home section.
